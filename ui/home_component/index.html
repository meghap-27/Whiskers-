WHISKERS

Ask questions about your spreadsheet.

Whiskers writes the SQL, runs the statistics, and tells you when a number is misleading: duplicate rows, outliers, small samples, Simpson's paradox. You can see every query it ran.

Sample questions

These ask about the sample retail data. Upload your own file in the sidebar and they are rewritten for it. Hover a folder, or tab to it, then pick a question.

Hover a question to see what Whiskers checks before answering.
